# Employee Salary Analysis

**Organization:** Veda Technology  
**Task:** Task 3 — Employee Salary Analysis  
**Language:** Python 3  
**Tools:** Visual Studio Code, CSV, GitHub

## Project Overview

Employee Salary Analysis is a Python program that processes employee salary records and calculates the total, average, highest, and lowest salary.

## Objective

To practise numerical data processing in Python and use built-in functions to summarize salary data.

## Problem Statement

Calculating salary statistics manually can be repetitive. This project automates the calculations and presents the results in a clear format.

## Dataset

The file `employee_salaries.csv` contains fictional employee IDs, names, and salary values. The sample data is intended only for demonstration.

## Features

- Reads employee data from a CSV file.
- Calculates the number of employees.
- Computes total and average salary.
- Identifies the highest and lowest salary.
- Identifies the employees receiving the highest and lowest salaries.
- Validates numeric and non-negative salary values.
- Reports invalid data and missing files.

## Technologies Used

- Python 3
- CSV file processing
- Visual Studio Code
- GitHub

## How to Run

1. Install Python 3.
2. Download or clone the repository.
3. Keep `employee_salary_analysis.py` and `employee_salaries.csv` in the same folder.
4. Open the folder in VS Code.
5. Run the command:

   `python employee_salary_analysis.py`

On Windows, you can also use `py employee_salary_analysis.py`.

## Calculations

- Total salary: Sum of all employee salaries.
- Average salary: Total salary divided by the number of employees.
- Highest salary: Maximum salary value.
- Lowest salary: Minimum salary value.
